## 用途与兼容核查

- `symbol_references.json` 记录原符号的源码/配置/脚本/测试/文档位置；`dynamic_calls.json` 列出动态导入、getattr、序列化等 178 处名称匹配候选（含普通 evaluate/eval 调用），结合符号引用核查。没有把简单字符串零命中等同于全世界无调用。
- `checkpoint_metadata.json` 只读取原始 densekp.ckpt 的 274260 字节 data.pkl 元数据；没有读取 tensor storage、实例化 DenseKP 或推理。所选 checkpoint 没有旧 loss/helper 引用，但不能排除外部 pickle，故旧类路径保留。
- 旧 helper 具有不同历史公式/插值/错误处理，不能无证据替换为当前函数；因此迁入显式兼容区，并从当前调用链移出，而非删除外部接口。
- Hydra 文件名是动态选择入口；遗留 HMR/BEDLAM 配置保留原值，不改默认 data=unselected，不启用失效字段。datasets.example.json 标为早期示例。
- 眼部坐标生成、皮肤审计、BVH 复查、衣物试验等保留唯一复现用途；失败产物和旧配方均未删除。
