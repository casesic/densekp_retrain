# F02 / M02 通勤衣物修复与失败归因

日期：2026-09-30。**结论：仍需修正；本轮没有证明衣物修复方法能跨 P1/P2 成立，不能扩十人，也未进入 DS。**

身体、shape、原始姿态、138 点和已有 groom 保持不变。参考姿态的胸腹衣型、领口、裤装裆部外表面有所改善；重新绑定与独立碰撞检查揭示了另外的失败。不能把静态改善、绑定回读成功或零三角形相交单独当作服装验收通过，也不能据此断言 P2 永远无法着装。

本轮按“F02 上衣参考姿态 → P2 → P1”推进，再分开检查裤装、M02 上衣和领片。所有产物继续 `integration_only`，旧版本和失败版本均保留。

## 失败分别来自什么

### 静态衣型和组件接缝

旧 v4 的胸腹使用区域硬阈值叠加椭圆松量，参考姿态已能看到凹凸和突变。这是静态衣型问题，无须先归因于姿态。单独拆出上衣后，F02/M02 参考上衣自身与人体的三角形穿插均为 0；旧“整套服装自交”还包括上衣和裤腰互相交叠，不能全部算成上衣内部自交。

对旧 v4 分组件检查得到：

| 参考姿态组件 | 与人体相交对数 | 组件自身相交对数 | 其他问题 |
|---|---:|---:|---|
| F02 上衣 | 0 | 0 | 胸腹波纹；与裤装交叠 98 对 |
| F02 裤装 | 68 | 155 | 集中在裆部，不是参考人体自交；该人体裆部检查为 0 对 |
| M02 上衣 | 0 | 0 | 衣型突变；与领片/裤装等组件交叠 |
| M02 裤装 | 242 | 331 | 裆部派生衣面和松量失当 |
| M02 旧领片 | 24 | 0 | 与上衣等组件相交 215 对，且外观僵硬 |

证据：`diagnosis/component_attribution.json`。相交对数依赖网格密度，不能跨不同拓扑直接当作严重程度排序。

采用连续曲面平滑而非继续逐点加大推开，将 F02 上衣参考胸腹突变消除。随后检查实际肩部高度再裁掉多余颈筒，避免重新切掉肩峰。该候选仍保留原袖口、长袖和下摆松量；不是换回旧运动 4 mm 壳层。

另实际测试了独立椭圆躯干/锥形袖的连续等值面拓扑。首版虽然静态不相交，但肩部被平面截断、袖子鼓起，视觉失败；P2 也失败。因此没有把“重做连续衣片”写成已经证实的唯一解法。

裤装采用有向扫描线的衣物/被覆盖人体区域并集，再生成外表面，以消除裆部内部衣面。它是**几何包络整理，不是物理布料模拟**。初版有明显体素条纹，Taubin 平滑未充分消除；对体积距离场过滤后 F02 参考局部外观改善，两人的参考几何穿插检查均为 0。仍未据此验收骑行裤装。尝试用水平包围盒平面重开腰口/裤脚失败：法线偏移后的原边界实际不共面，残留盖片会穿入人体；该失败保留，代码现在拒绝这种输入。

M02 新领片使用五排曲面和前开口，先改接触方向避免投到上衣下侧，再把前端改为下垂。参考状态与人体/上衣的三角形相交均为 0，但领片仍偏大、偏硬，门襟和完整 polo 尚未验收。

### 姿态绑定与修碰

平滑衣型后沿用旧表面锚点不可靠。本轮重新用全网格 BVH 最近表面计算重心锚点、插值骨骼权重，并比较原“人体表面锚点 + LBS offset”与整件衣物的双四元数绑定（DQS）。DQS 只用于衣物，没有替换 SMPL-X 人体的模型或变形。

重网格裤装还暴露出明确的绑定不连续：参考衣物上长度小于 5 mm 的短边中，F02 有 328 条、M02 有 373 条两端权重 L1 差大于 0.5；绑定后部分边被拉长数十倍以上。这是最近人体表面在腿/裆部切换的缺陷，不能推给人体腋下。

在**同一参考衣物图**上平滑权重，供 P1/P2 共用，以上短边跳变降为 0，未改衣物参考顶点或人体。F02 裤装修碰位移降至约 23–28 mm；但点接触投影仍产生大量局部面翻折，自交没有解决。由此保留了一个具体结论：权重连续性是必要修正，单靠它和逐点外推仍不足以形成可靠服装。

记录在 `F02_trouser_weights/`、`M02_trouser_weights/`、`*_trousers_rebound/`、`*_trousers_smooth_binding/`。松量、重绑造成的变化和后续修碰分开保存，没有把它们合成一个“通过的偏移”。

### 原身体重叠和求解过渡

初次宽上肢筛选得到 F02/P2 的 131 对相交，包含部分前臂，**不能全部叫腋下**。最终采用参考面中心 `0.12 < abs(x) < 0.30 m`、`0.28 < y < 0.47 m` 的限定区域：

| 既有 P2 几何（全部只读） | 同一已核验面序区域内相交对数 |
|---|---:|
| 照片转换得到的原 SMPL-X | 73 |
| 旧 F02 v1 | 89 |
| 当前 F02 v2 | 88 |
| 旧 M02 v1 | 85 |
| 当前 M02 v2 | 88 |

F02/P2 的 88 对涉及 89 个面；这些面的内侧 1 mm 采样中，48 个全网格 solid-angle winding 大于 1.5。DQS 上衣最深失败点周围 ±3 mm 的 27 个采样中，23 个处于双层人体内部。参考姿态同一区域相交为 0，F02/P1 为 8。问题早于本轮衣物和新 shape，不是一个 winding 样本推出来的结论。

旧两次 cloth simulation 的输入、结果、验证已核对。另以**参考姿态无穿插的独立上衣**复测原 P2 初始化路径，去掉原本相交的裤装/领片，保持原 v6 的 130 帧、刚度、质量和碰撞距离，不加全局软 pin：

- 第 10 帧：人体/衣物和衣物自身相交均为 0。
- 第 60 帧：出现 24 对人体/衣物相交；原保存的身体过渡也在约中段开始出现上肢重叠。
- 第 130 帧：894 对人体/衣物、235 对衣物自身相交，最大偏移 109.12 mm，失败。
- 实际碰撞体启用；末帧身体与目标差异 5.96e-8 m。输入、关键帧和配置保存在 `F02_top_isolated_cloth_P2/`。

此外，F02/P2 外包络整理可以得到一个三角形穿插为 0 的外表面，但旧绑定衣面到该表面的最大反向距离为 69.72 mm；DQS 版本为 66.99 mm，并残留 5 对人体相交。最大距离位于参考正 X 侧上臂下方，不是领口切盖误差。没有只报告向外新表面约 4 mm 的距离来掩盖被移除的内部衣面，也没有放宽 60 mm 上限。

这些证据支持“当前绑定在 P2 人体重叠处不能可靠着装”，**不构成任意服装方法都不可能的证明**。受影响面面积不是穿插体积，包络距离也不是经认证的最短人体脱离距离。

## 独立数值核验与限制

新增 `commuter_intersections.py` 使用 Blender BVH 候选和双向边—三角形交叉计算，不依赖旧“最近 24 个质心”和顶点/面中心采样。自交排除共享顶点的相邻面。

回归测试发现 BVH 可能不返回共面相交，所以最终函数对共面状态返回 `null`，不把初始记录中的 `0` 解释为通过。穿插对数也不能检测完整包含；因此报告只有“非共面交叉检查候选”，没有“穷举无穿插”的宣称。范围修正和早期元数据问题集中记录在 `diagnostic_errata.json`，原结果未删除。

重新用旧参数还原六份身体，结果为：

| 检查 | 最大误差 | 不变门槛 |
|---|---:|---:|
| 人体参数 → 保存网格 | 0 m | 2e-5 m |
| pelvis/root | 0 m | 2e-6 m |
| 138 点回归器 `R @ V` | 5.96e-8 m | 1e-6 m |
| 本轮 31 份组件证据内的身体/面序 | 与原文件逐数组完全相同 | 不允许修改 |
| 衣物绑定回读（包括 DQS 独立旋转回读） | 2.31e-7 m 以下 | 2e-6 m |

新实验保存 DQS 四元数/平移或父衣物三角形重心、修碰/重网格改变量；它们**不是已经接入 DS 的 `commuter_surface_binding_v1` 成品**。旧生产入口和 `studio_accepted` 拦截保持不变，未接通这些失败候选。

世界人体/衣物一致性仍要求 5e-6 m，投影及裁剪仍要求 2e-4 px；本轮没有新 DS 数值可报告。后续仍用 20260320 标定和显式有效区域 mask，不能混入 031。监督仍为 `in_view & inside_full_crop`，遮挡状态独立；未把 `keypoint_value` 用作置信度或权重。

7 项 Blender 几何回归测试通过，覆盖边穿面、分离、相邻面、共面未知、有向并集不作 XOR、DQS 刚体等价及四元数符号；另 1 项既有衣物回读/棚拍门禁测试通过。没有运行网络推理或训练。

## 下一步必须分别解决的问题

1. **保留静态改善，先修衣物的语义绑定与面级接触。** 裤装以腰、左腿、右腿和裆部桥接的连续控制网格定义权重，再细分到渲染网格；不要再次从高密度等值面逐点独立选最近人体区域。新领片应绑定到上衣颈圈的共同控制变形，不能各自只对人体修碰后就视为接缝成立。仍先局部验收，再完整服装与 groom。
2. **对 P2 提交派生姿态修正建议，本轮不执行。** 来源保持 `coco_306800_person_225160` / 原 `canonical_pose.npz`，保留原组合失败状态。优先检查标准 SMPL-X 左锁骨/左肩/左肘关节（13/16/18；`body_pose` 去 root 后索引 12/15/17），针对已保存的正 X 侧腋下相交面，求最小姿态变化；右侧小面积问题另列。可先以肩部 5° 的小范围搜索作试探，**未验证足够，不能承诺影响范围或通过**，不得改 betas、局部顶点或 expression 来避碰。
3. 派生姿态若获准试验，应另存新版本，报告每关节角差、身体/138 点位移分布、pelvis、手腕位置、原照片可见关节重投影变化及独立自交变化；重算绑定、衣物和 groom 接触。不能因新增视角或姿态修正就增加独立姿态来源数量，也不能据此把 `integration_only` 改成正式验证集。
4. 只有两角色 P1/P2 衣物、接缝、视觉及 groom 接触全部通过，才恢复有限 DS 双相机验证。当前没有理由扩大十人或训练规模。

这里没有把“修改姿态”当作替代全部衣物修复的办法：参考裆部错误、最近表面权重不连续、领片—上衣相交都有各自证据，仍需要分别修正。

## 工作量与边界

本轮累计约 1 小时；精确起止与各阶段记录以 [timing.json](../../outputs/experiments/cycling_commuter_repair_20260930/timing.json) 为准。已计时子进程约 534 秒，包含计算/局部渲染，部分与代码适配和审查重叠。适配与归因约 40–48 分钟、视觉审查约 6–10 分钟是回顾估计，不伪装成独立秒表数据，也不能与计算时间直接相加。

仍是 2 个身份、2 个独立姿态来源、4 个目标组合；完整服装通过数 0。保存 42 张组件灰模和 3 张截面图，无完整角色批量重渲染，DS 0。保留 31 份组件绑定试验及相关失败体积/求解记录，它们不增加数据集样本数。

计算前核查了主机进程与 GPU（两卡空闲；已有 Blender GUI 保留），本轮使用 CPU 诊断/局部渲染。没有下载、照片重建、采购、训练、推理、datasets 迁移、SHA256、commit 或外部项目修改；已有未提交改动不作清理。
