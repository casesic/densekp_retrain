# APD 连续骑行动作与轨迹可用性审计

日期：2026-10-08。状态：**小规模审计完成，停在评审点；没有拟合或接入生产。**

两个结论独立成立：

- **连续姿态：需补证。** 三个窗口确有时变下肢和部分交替屈伸，但尚未确认两个合理、完整的连续蹬踏周期。骨长变化、右脚跳变、缺失、足端定义及坐标约定不足以支持直接进入穿衣 SMPL-X 制作。没有把全段 `move` 标签当成持续蹬踏证据。
- **场景轨迹：建议复用，范围限于两条持续移动路径的形状候选。** `6526`、`6900` 的头部 XY 路径可作为离线场景路径模板，经显式尺度/道路放置和时间策略评审后再接入。**起停完整性、转弯、真实 pelvis/root 和地面轨迹仍需补证**。这不是 APD 全库通过，也不是整套六类状态已验收。

### 14 点顺序与骨架

JSON 原本是按关节名取数组。为审计固定以下本地顺序，**不是官方声明的 packed array 顺序**：

`head, thorax, lshoulder, rshoulder, lelbow, relbow, lwrist, rwrist, lhip, rhip, lknee, rknee, lfoot, rfoot`。

已查看 [官方骨架图](https://github.com/kav-institute/aschaffenburg-pose-dataset/blob/master/img/skeleton.svg)。连接为 `head–thorax`、`thorax–左右shoulder`、左右 `shoulder–elbow–wrist`、左右 `shoulder–hip`、`lhip–rhip`、左右 `hip–knee–foot`。注意图中是 shoulder 到 hip，不自行改成 thorax 到 hip。`l/r` 按官方左右命名；是否在某帧错换另做诊断。没有 pelvis 点；髋中点只是本轮派生平移参考。`foot` 未给足够精细的踝/趾/跟解剖定义，后续约束 SMPL-X 前必须明确映射。

## 4. C：对接推断与最小后续方案（本轮未实现）

### 姿态若补证通过

先评审 `6526` 已审计窗口内的一小段，标出至少两个完整合理的左右交替周期及具体源帧，确认原坐标规范和 foot 对应。当前没有足够证据冻结“合格拟合子段”，不能为了预算随意指定首几秒。若无法取得完整坐标文档，可另提“相似变换对齐的部分关节拟合实验”，明确尺度/朝向是估计且不恢复真实root；该选择需单独评审，不暗中当官方米制坐标。

14点可约束粗略头/躯干与肩髋位置、四肢方向及肘膝弯曲；不能唯一约束骨骼扭转、详细脊柱、头部旋转、脚趾/踝细节、手指、脸/眼/下颌/表情。后者固定或使用先验，并逐参数标为 fixed/estimated/unobserved。3D完整率高也不代表可靠度高，不能用 pose2d 第三值直接加权。

制作方最小交付仍是一个固定目标角色（建议沿用 A2 的一个成人，而非估计源人物身份）、固定目标 beta/模型/拓扑、连续 SMPL-X 参数及既有衣物/groom 绑定；逐帧权威缓存可替代，不要求重复全存。拟合以有效关节掩码、稳健位置/方向约束和时间正则为基础，不逐帧改 shape 来跟踪 APD 骨长噪声。短缺失如需求隐变量必须标 estimated，原缺失仍保留；无法稳定恢复则切段/拒收，不把时间轴压紧。无 RGB、无相机参数时不假称重新做过视频重建。

接入侧仍从 **身体网格通过现有 `R[138,10475]` 回归138点**，不能把14点插值成138。身体、衣物、groom、138点必须同一帧和同一变换；头发随头正确运动即可，衣物允许轻微局部穿模，明显翻折、脱体或持续闪烁不通过。不要求毛发/衣物物理、自行车或 Unreal→Blender 完整流程。

### 轨迹可先独立推进

下一批最小路径任务只选 `6526` 或 `6900` 一个已审计十秒窗，输出离线**轨迹草案**及映射表，暂不需要人体模型/GPU。建议先用 `6526`；路径来自头部 XY，必须声明它是路径形状参考。减首点后映射到道路平面，显式确定长度、场景朝向、路面高度/骑行放置高度及采样时间。原坐标和提供的 RTS 轨迹保留；若还需低频路径拟合，另存参数和结果，不能覆盖原始序列。不能把 raw `head.z=0` 当地面，也不能把 head 或髋中点直接命名为 SMPL-X root。

首方案只采用 **原地动作＋场景轨迹**：动作源去掉负责行进的源平移/航向，只留声明的局部root残差；场景路径负责一次平移/朝向，轴向转换只做一次。源 `global_orient` 与场景 yaw 分工明确，不能把已烘焙航向再旋转一遍。备选“保留源root＋固定放置”与本方案互斥；此时不能再叠 APD 平移。新连续入口使用固定放置或显式地面轨迹，禁止逐帧 min-Y 抬升造成跳高。

若 APD 姿态后续仍不过关，可只用路径配合**另一个已验收骑行动作来源**；本轮不自动重启 BVH 路线。两来源的时间映射要分别记录，不把道路速度统计当作蹬踏验证；变速/重采样有逐帧源时间、区间和权重，动作/衣物/头发共用映射。首段不循环；以后循环需另验 pose/root/衣物/头发的位移和速度接缝。缺帧留标记或拒收，不默默平滑、补帧再称原始。
