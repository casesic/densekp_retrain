## 1. 业务目标与范围

实际输入是同一场景的两路鱼眼视频，各自转换成 ERP。位于两相机交界处的人体会同时出现在两路图像中，但两侧往往都不完整。DenseKP 的任务是提供同一人体的 138 个语义位置，支持两视角中可用点的对应，供后续合图使用。

因此，本阶段重点是：**双视角边缘、不完整人体在连续运动和多人遮挡条件下的可靠语义点对应**。骑行、行人、交会和框扰动围绕这个目标组织。

- 边缘指实际鱼眼有效成像边界及实际检测 ROI 附近的目标区域，不能直接等同于 ERP 左右接缝。
- “两边都拍到这个人”不保证两边有足够共同有效的语义点。共同点不足或完全遮挡的时刻必须单列，不通过域外点强行凑对应。
- 项目范围：人物/动作数据、合成成像与标签、DenseKP 训练、点与点对评价。
- 范围外：人体检测器本身的改进、检测漏检召回、最终合图算法。允许只读核查部署链和统计实际 YOLO 框；给定目标身份的配对评价不代表身份关联问题已解决。

## 2. 已确定的要求

1. 需要视频和连续 motion。骑行优先寻找公开且无需付费的视频，连续片段中的同一人物才可作为时序重建来源；逐项保留许可和来源信息。
2. 现有两个照片重建姿态是独立静态姿态，保留作历史对照，不能拼成共享 shape 的连续动作。
3. 人物穿衣，允许局部轻微穿模。用户负责标准资产制作/适配流程；不再将零相交作为通过条件。
4. 使用现有 5 男 + 5 女角色候选库作为起点，保持外观多样性。儿童不阻塞本阶段；人物家族与外观来源的既有划分限制继续生效。
5. 做 2–3 个有规则的场景模式，通过随机种子生成多段序列，变化人物、衣服、动作、轨迹等。
6. 重点覆盖双相机交界的边缘人体，不要求场景里的每个遮挡者都在边缘。
7. 框增强针对实际检测框误差，不以大量不合理扰动取代真实困难条件。
8. 后续新数据采用源 ERP 5760×2880、DS 鱼眼 2880×2880、最终 ERP 5760×2880；尺寸顺序为宽×高。默认 compact，full 按需用于诊断。
9. 候选和实验先写入 outputs；验收及划分确定后才打包到 datasets，检查依赖路径，保留原实验记录。

## 4. 全程保持的技术约束

- 138 点语义与身体回归算子固定，不套用 BEDLAM 官方点索引。衣物、头发不改变点的语义定义。
- 图像和点使用一致投影、裁剪及坐标转换；身体、衣物、头发与点共用世界变换。连续帧不能各自任意贴地而引入跳动。
- 真实目标与标定为 20260320-riding-dataset3，不混用 031/0311。双相机相对位姿需对照实际部署核查；现有 0.18 m 是合成设置，不能当成实测外参。
- 不用黑色 RGB 判无效区，使用显式 mask；边缘距离计算也要考虑 ERP 周期与实际成像域，避免把接缝误当镜头边界。
- 在当前显式合成监督策略下，每视角独立按 `in_view & inside_full_crop` 确定监督。可靠遮挡 GT 仍参与训练和评价；双视角共同集合仅用于配对评价，不替换单视角监督集合。
- 预测第三值不能默认当置信度或权重。允许标签不参与 loss，不等于网络已经会判断“未知”。
- 输入/标签是完整 256-square，骨干取中间 192 列；还原不额外加 32 px。
- 点对用 `(sequence_id, time, person_id, semantic_id)` 对齐。不能把不同相机像素直接相减作为对应误差。
- 先验证时间同步与帧对应，再讨论时序收益；平滑后的轨迹不能被冒充独立的真实 GT。

## 5. 阶段任务与验收

### T0：定义真实交界区域、框误差与评价协议（最高优先）

**目标**：把“边缘”“不完整”“可用点对”和“合理框增强”变成可测量定义。

范围：只读核查 pano-stitch 的实际鱼眼→ERP、检测 ROI 和坐标链；整理已有真实双路视频/帧、标定、YOLO 框及时间戳。优先复用已有结果，缺少检测结果时先列出待计算范围，不擅自运行。

产物：

- 双视角有效域/检测 ROI 图，说明交界区域如何定义；从三维人物投影检验两侧覆盖，不仅用两个二维 mask 简单相交。
- 选定真实片段索引、时间同步和帧映射说明、参考框定义及来源。
- 框偏移（按参考人体尺寸归一化）、尺度比、单侧截断、可见比例及邻人侵入统计；没有可靠参考框时只描述检测变化，不能称为检测误差。
- 冻结评价协议草案：共同有效点数、分组、阈值单位、无共同点处理、正常样本回归门槛。

验收：坐标与时间对应可追溯；能够在实例上解释“人在哪个边缘、两边分别缺什么、哪些语义点共同有效”；缺失标注和待决定阈值单列。

### T1：连续骑行动作与穿衣角色样例（用户资产流程 + 执行侧接入）

**目标**：先交付一段可用的连续骑行序列，不急于扩大动作库。

范围：公开视频候选与许可核查；选取同一人物的连续片段进行时序重建/适配。动作内部姿态变化与全局行进轨迹分别表示，避免源 root motion 和场景轨迹重复叠加。固定姿态沿路平移不能当作连续骑行动作完成。

建议输入契约：源视频/片段/人物 ID、原始与采样时间戳、帧率、长度单位、坐标轴、shape、逐帧 pose/root transform、角色与衣物/头发绑定、处理版本和许可来源。变速、重采样及循环需记录映射，不用轴角逐分量插值掩盖接缝。

产物：连续动作与角色 manifest、几何/138 点回读记录、穿衣多视角检查视频、接入缺口表。视频显示帧率与数据时间戳一致，明确是否循环或变速。

验收：蹬踏与躯干变化连续；无人物身份/shape 跳变、明显关节翻转、轨迹突跳或衣物大面积穿插；允许不影响主要轮廓的轻微局部穿模。检查连续播放中的闪烁，而不仅看静帧。手指/车体接触等未恢复细节如实记录，不强制新增自行车资产。

本阶段只认可单片段接入；后续独立验证若需新的骑行来源，不能用同视频邻段或循环版本代替。

### T2：高分辨率框处理与最小序列输出

**目标**：把现有 C + compact 能力接到连续样本和后续框增强，保持旧实验兼容。

范围：

- 新框计算显式使用实际图像宽高；旧 1536×768 行为保持可复核。定义边界、接缝、空框和非有限值规则，不暗中统一历史策略。
- 对帧号、时间戳、人物 ID、动作帧、相机、seed/episode ID 建立一致索引；身体、衣物和标签使用同一时刻。
- 后续默认 compact，逐任务成功验收后清理源 EXR/RGB；失败保留。full 用于指定诊断，不扩展历史清理。
- 新增按序列生成的轻量双路/并排检查视频；视频用于观看，不替代训练 PNG 或138点标签。用户明确需要视频，因此保留这项必要产物，不恢复逐帧 overlay 和重复拼图的默认输出。

产物：序列字段契约、尺寸感知框入口、最小配方、定向检查和存储统计。

验收：5760×2880 框不会误裁到1536×768；旧尺度回归通过；图像/GT/affine 一致；临时源清理后仍能打包、loader 回读和实际新框增强。验证含跨帧变化、域边缘及截断，不只数文件。

### T3：先实现一个受约束的随机场景模式

**目标**：先把“种子→配方→连续双视角数据→覆盖统计”完整跑通。

首选建议：沿道路通过的 1–5 人骑行队伍，经过 T0 定义的交界区域；用错开的发车时间、合理间距和视线关系形成前后遮挡。

产物：模式配置、确定性配方生成器、冻结 seed 与 episode 清单、双路视频、逐帧标签和覆盖统计。先输出几何投影/轨迹计划审核，再做有界真实渲染；具体时长和数量在执行任务中冻结。

验收：相同配置、资产与随机算法版本下，seed 可恢复同一人物/衣服/动作/轨迹配方。不能承诺不同渲染器版本间RGB逐位一致。目标在两侧有效域边缘有足够停留和共有点机会，包含进入、截断、遮挡及恢复过程，不能只在开头一帧碰到边缘。

### T4：扩成 2–3 个模式并冻结数据设计

候选模式（方案建议，尚未全部批准实施）：

| 模式 | 参与者和路线 | 主要条件 |
| --- | --- | --- |
| 沿路通过 | 1–5 人骑行队伍，顺序经过交界 | 人体尺度、截断、前后遮挡 |
| 双向交会 | 骑行队伍与迎面或斜向行人交会 | 短时遮挡、邻人干扰、框变化 |
| 三岔路口 | 来自不同支路的骑行者/行人汇入、穿越或转弯 | 交叉轨迹、朝向变化、多次遮挡 |

同一 seed 可派生多个 episode，但必须保存子种子及全部实际抽样结果。人数、角色、衣服、动作起始帧/相位、速度、间距、入场时间、轨迹和场景放置分别可控。衣服只能从已验收组合中采样，不能任意混搭就宣称通过。

相机全局位置/朝向可在验收范围内采样；双相机相对位姿及标定固定。若研究不同 rig，应显式分组，不在普通随机项里混入。

空间规则：沿道路/可行区域运动、速度和转弯合理、人体不严重互穿。允许轻微衣物穿模不代表允许人穿人。遮挡通过合理视线、间距与时序制造。

产物：模式参数表、有效范围、拒绝条件、目标覆盖配额、片段/人物/帧数预算及存储预算。按双相机帧统计存储；现有25.80 MiB/帧对仅作估算，场景及角色不同需实测。

验收：覆盖率来自投影/标签统计，不凭肉眼认定；保留少量完整或轻遮挡对照，具体比例待冻结。困难程度按边缘距离、截断、可见/监督比例、双侧共同点数、人体尺寸和框误差分列，记录未达配额及拒绝原因，不以模型误差筛数据。

### T5：来源隔离、采样与冻结小规模训练数据

**目标**：从连续序列得到可追溯、无相邻帧泄漏的小试数据。

- 先分配人物家族、源视频/人物/动作片段，再生成场景。包含全部遮挡者，避免一场序列把预定train和val来源连在一起。
- 同一源片段的重采样、速度变化、循环、衣服衍生、双视角、所有邻帧按组隔离；换 seed 不自动形成独立样本。
- 区分来源独立验证和共享来源诊断，无法独立的部分明确标记。未知皮肤供体、预训练资料重叠等限制仍保留。
- 保留完整序列索引，训练帧按固定时间间隔和事件配额抽样；不要用大量近重复帧冒充大量独立动作。
- 接入 T0 的合理框扰动范围，单视角裁剪后独立重算监督；参考框、可见区域框和真实/模拟检测框注明类型。

产物：冻结train/val及测试或诊断分组、来源关系、采样清单、框增强配置、原始权重基线、打包/loader验收和路径依赖清单。

验收：组间来源检查通过；同帧双相机与邻帧无泄漏；数量、单位和共同点分母清楚；无GT或无共同点不计成零误差。不得仅因模型表现差删除困难样本。数据规模及比例经评审后才打包至 datasets。

### T6：按配对收益做小规模微调和评价

**目标**：验证困难条件下的点对质量是否改善，同时控制正常样本退化。

先保持现有网络与监督语义，从原始权重出发，比较同一冻结数据上的基线和受控微调。训练预算、数据混合比例、增强范围、checkpoint及验收门槛在训练前确定，不把历史400步当自动预算，不根据结果临时挑最好checkpoint替代主结果。

评价最少包含：

- 单视角：可见/遮挡、截断、边缘、人体尺度分组的crop误差与ERP周期误差；等点和等人物口径分列。
- 双视角：同一人物同一语义点两端各对自身GT的误差、较差一端误差，以及两端同时达标的点对数量/比例。
- 可用性：按预先冻结阈值统计每个人/时刻的有效点对数和人体部位分布；“有很多点”不自动代表空间分布足够合图。最少点数与分布要求和下游共同确认。
- 覆盖：双侧可见、单侧遮挡、双侧遮挡、只在单侧有效、无共同点、完全遮挡分别统计。共同GT集合不能由预测筛选。
- 回归：完整人体、轻遮挡、既有骑行和混合样本的退化门槛；实际YOLO框与合成扰动分开报告。
- 时序：优先衡量预测残差随时间的跳变及对应关系稳定性，不能把真实运动本身计为抖动。

GT阈值产生的“可用点对”是离线评价，不是部署时可获取的可靠性输出。真实帧标注不确定的点单列；没有真实GT不能宣称真实精度提升。最终合图收益由下游另行验收。

产物：固定对照表、成功/退化案例视频、适用范围与失败边界、权重与严格重载记录、后续决策。只通过流程不等于通过效果；没有部署认可不替换原权重。

### T7：按失败证据决定网络或时序方案（条件性后续）

如果数据与合理框增强仍不能解决关键失败，再分别评审：

1. 目标人物提示：帮助模型区分裁剪中的目标与邻人，具体输入设计另议。
2. 点可靠性/未知输出：独立命名、独立标注和校准；同时评价覆盖率与误差，禁止全部拒绝换取低误差，不复用第三值为未经验证的置信度。
3. 上一帧辅助框：先有明确的人物关联和因果时间链，仅使用过去帧预测；包含启动、失跟和遮挡恢复，不用未来帧或GT框冒充可部署结果。

这些不是本阶段默认实现项。连续数据先保留相应身份、时间及轨迹信息，允许以后验证。

## 6. 执行顺序与近期首批任务

主线：`T0 → T1/T2 → T3 → T4 → T5 → T6 → 按证据决定T7`。

T0 的只读调查可与用户资产流程并行；正式轨迹/数据配额依赖 T0，首个完整动态场景依赖 T1、T2。分阶段验收，不将本文件视为一次性执行全部任务的授权。

**下一次执行对话的首批建议任务**：

1. 只读核查真实检测 ROI、双路时间/坐标链及已有框记录，交付边缘区域定义和缺口表（T0）。
2. 列明连续骑行资产交付字段，与用户确认其制作结果如何接入；有本地候选时先核查，不重复下载/重建（T1准备）。
3. 给出高分辨率框裁边及序列输出的最小改动清单（T2规划）。

首批停止于方案评审；随后单独下发实现、视频获取/重建、有界渲染和训练任务。明确数量/时长/资源预算后再计算。
