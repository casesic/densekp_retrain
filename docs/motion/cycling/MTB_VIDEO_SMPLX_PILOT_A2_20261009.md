## 2. 本地路线与接口修复

实际路线：**现有 SAM3DBody-cpp CUDA ONNX → MHR 网格 → 官方 MHR→SMPL-X 重心映射 → 官方 PyTorchSMPLFitting**。

- Python Fast-SAM-3D-Body 环境存在，但checkpoint及mhr_model.pt链接指向 `/home/yuyue/.cache`，该目录为0700，本用户在主机读权限下仍不可访问。没有修改权限或下载替代权重。
- C++后端已有完整可读ONNX/GGUF/LBS资源和编译程序，可从单张图＋外部框导出原始网格、相机、关键点。每帧独立启动并保存，避免其视频导出固定文件名覆盖结果，也不编译新接口。未执行benchmark、检测器、TensorRT构建或外部demo默认输出。
- 4D-Humans只读核查到代码、SMPL基础模型及指向cache的默认网络权重配置；未运行，也未把SMPL直接冒充SMPL-X。本轮没有切换第二条网络路线。
- 首次C++加载因cuDNN9不在动态库路径失败。库实际已在sam3dbody环境中；只设置该进程 `LD_LIBRARY_PATH` 后成功，没有安装或升级。
- 转换首次因旧PyTorch不接受numpy uint32面索引失败；独立适配器改为int64，失败日志保留。CPU回读首次因默认jaw/eye仅batch1失败；显式传入逐帧零值后成功。这些是读取/求值接口修复，没有修改姿态以掩盖问题。

外部源码/模型始终只读。缓存和日志重定向本轮目录，关闭Python字节码写入；没有修改pano-stitch、公共生成器或项目模型代码。

### MHR拓扑证据

没有直接继承旧 `parity_summary.md` 的结论。按当前C结构定义读取 `body_mesh.tri`，头长136字节，名称正确为`mhr_body`，36874个三角面、最大顶点18438，与保存的官方Python `faces.npy` **逐元素完全一致**。提前4字节读取会出现旧报告所示的空字符名称和错误面集。见 `topology_evidence.json`。

## 3. 共享shape、拟合与时间处理

5帧探针联合估计一组10维beta，`single_identity=True`；之后将该beta作为 `known_parameters` 固定，重新求值并优化完整120帧的姿态。全段beta逐值一致且等于探针结果。不是先逐帧变shape、导出时再改成一样。

使用既有标准male SMPL-X模板，10475顶点、20908面，原生顶点顺序不变。male是本轮适配模板选择，不声称准确还原源人物体型或身份；下一轮再选择与M01不同的目标角色。

官方拟合每批采用40/80/40步粗优化＋300轮细优化，batch10；探针一个批，完整段12批。完整段共5520次参数更新，探针460次。网络权重无更新。`is_tracking=False` 明确保留：该短段没有伪称调用tracking即具备时序约束。首版姿态独立拟合，共享并固定shape，随后对完整时间轴检查连续性。

没有执行追加平滑/修正版：最大变化位于踩踏膝屈伸相位转换，检查附近连续帧未见180°翻腿或孤立手臂翻转；没有明确失败依据时不消费修正额度。全段视频留给用户判断是否还有不可接受抖动。

## 4. 坐标、root与估计字段

原始C++输出为相机约定：x向右、y向下、z向前；`vertices_camera = pred_vertices + pred_cam_t`，只加一次。投影使用每帧保存的fx/fy/cx/cy和这个相机网格。C++默认焦距约2202.9像素是模型/图像尺寸假设，不是真实标定；3D米制是模型尺度，不宣称真实尺度。

映射接口按官方公式先把MHR米乘100交给厘米接口，映射内部再乘0.01；结果和SMPL-X使用模型米。没有逐帧缩放。

资产版执行一个固定正规旋转 `A=diag(1,-1,-1)`：

```text
vertices_asset(t) = A @ [vertices_camera(t) - pelvis_camera(t)]
global_orient_asset(t) = A @ global_orient_camera(t)   # 矩阵复合
transl_asset(t) = -shaped_rest_pelvis                  # 全段常量
```

实际常量平移为 `[-0.0007643923, 0.3590494394, -0.0003849273]` 米。全段pelvis位于原点，global orient的帧间变化保留，不逐帧重新朝向对齐。被移除的相机pelvis与源相机参数完整保存，不用它们作为道路轨迹。场景以后拥有行进、yaw与固定放置高度；不得脚底/min-Y逐帧贴地或重复应用root。

头颈保留后端/拟合估计，隐藏部分明确标估计。双手45维和expression由MHR表面约束拟合；jaw/左右眼旋转默认零，没有独立估计。不要求精确车把/踏板接触，未补自行车资产。
