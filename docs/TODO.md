4. 明确了 DenseKP 的重点问题

面向两路鱼眼展开后，边缘、不完整及相互遮挡人体的138个语义点对应。

通过不同遮挡程度的对照，以及固定重遮挡图像、仅改变输入框的实验，发现：遮挡不仅造成身体信息缺失，还可能改变检测框的位置和大小；由此产生的裁剪变化会进一步影响 DenseKP 定位。 因此，后续需要同时提升遮挡条件下的定位能力和对输入框变化的鲁棒性。
